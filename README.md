# 들빛마을 시간여행 탐정단 v3.0

초등학교 4학년 사회 ‘들이 펼쳐진 지역의 특징과 변화’ 수업용 탐험 게임입니다. 귀여운 가상 마을에서 아바타로 탐험하고, 실제 사진·영상·항공사진을 근거로 조사합니다. Galaxy Tab 가로 화면과 전자칠판 사용을 고려했습니다.

## 이번에 추가한 실제 자료 조사

- **대전 항공사진**: 갑천 주변 도룡동·만년동 일대의 실제 1970년·2021년 항공사진을 같은 범위로 맞췄습니다. 나란히 보기·겹쳐 보기·비교 막대·확대·축소·동기화 스크롤을 지원합니다. 2021년 자료를 ‘오늘 촬영한 사진’으로 표시하지 않습니다.
- **농사 방법 조사**: 손으로 모를 심는 기록 사진과 농촌진흥청의 기계 모내기 관찰 영상을 비교합니다.
- **재배 시설 조사**: 실제 비닐하우스 내부 사진과 온실 관리 영상을 관찰합니다. 영상은 앱에 포함된 MP4로 재생·일시정지할 수 있습니다. 관찰용 무음 발췌 영상이며, 영상의 전문 수치를 외우는 활동은 아닙니다.
- **단서 직접 표시**: 실제 사진의 원하는 곳을 눌러 번호를 찍고 설명을 쓰거나 지울 수 있습니다. 사진을 확대한 상태에서도 표시 위치를 유지하며, 겹쳐 보기에서는 해당 시기의 보이는 영역에만 표시됩니다. 영상에서 본 것은 아래 기록 칸에 씁니다.
- **근거와 생각 구분**: ‘자료에서 확인한 것’과 ‘그것을 보고 생각한 것’을 나누어 기록합니다. 자동으로 정답 내용을 채워주지 않습니다.
- **조사 수첩**: 입력은 같은 기기에 자동 저장됩니다. 실제 사진·위치 표시·기록·출처를 포함한 독립 HTML 수첩을 내려받아 읽거나 인쇄할 수 있습니다. 수첩의 영상 자료는 대표 사진과 원문 링크로 담습니다.

## 학생 활동 흐름

1. 탐정 아바타를 고르고 부엉 박사에게 의뢰를 받습니다.
2. 주민과 대화하고, 가상 마을의 두 시대를 오가며 반짝이는 단서를 찾습니다.
3. 첫 세 의뢰는 단서를 모은 뒤 실제 자료 조사로 이어집니다. 논→농사 방법, 비닐하우스→재배 시설, 주거지→대전 항공사진을 살펴봅니다.
4. 학생이 직접 표시하고 관찰·생각 두 칸에 기록한 뒤 ‘조사 기록 저장’을 누르면 해당 의뢰를 마칩니다. 학생 해석의 옳고 그름을 자동 채점하지 않습니다.
5. 나머지 세 의뢰는 기존의 비교 문제로 진행합니다. 여섯 의뢰 후 탐정 인증서를 저장할 수 있습니다.
6. 상단 ‘현장 조사’, 연구소 앞 ‘실제 자료 조사소’, 단서 사진 아래 조사 버튼으로 언제든 자료를 다시 살펴봅니다. 첫 화면에서도 조사소에 바로 들어갈 수 있습니다.
7. 탐정 수첩의 ‘실제 자료 조사 수첩’에서 기록을 검토하고 내려받습니다.

## GitHub · Vercel 배포

1. 압축을 풀고 `index.html`, `style.css`, `research.css`, `src`, `assets`, `package.json`, `vercel.json` 및 문서를 GitHub 저장소 최상위에 올립니다. `src`와 `assets` 폴더 구조를 유지하세요.
2. 이전 버전의 `index.html`과 `style.css`는 덮어씁니다. 이전 `app.js`는 더 이상 사용하지 않습니다.
3. Vercel에서 해당 GitHub 저장소를 Import합니다. 이미 연결되어 있다면 새 커밋이 배포됩니다.
4. Framework Preset은 **Other**입니다. Build Command는 비워 두고, Output Directory는 **.** 로 설정합니다. 포함된 `vercel.json`도 같은 설정을 선언합니다.
5. 별도 환경변수, Firebase, 사용자 로그인, 유료 API 키는 필요하지 않습니다.

HTML을 파일 앱에서 직접 열기보다 Vercel 주소로 접속하세요. JavaScript 모듈이므로 웹 서버에서 실행해야 합니다.

## 조작과 저장

바닥을 누르면 길을 따라 걷습니다. 조이스틱·방향키·WASD도 지원합니다. 주민이나 단서를 누르면 가까이 걸어간 뒤 대화·조사합니다. E 또는 스페이스로도 상호작용합니다. 실제 자료 조사 중에는 게임 이동 키가 작동하지 않습니다.

게임 진행과 조사 기록은 같은 기기·브라우저의 localStorage에 저장됩니다. 로그인·Firebase·교사 수집·온라인 공동 플레이는 없습니다. 같은 주소로 들어가도 학생마다 독립 진행합니다. ‘새로운 탐험 시작’ 후 출발하면 기존 게임 진행과 조사 기록을 새로 시작합니다. 사이트 데이터를 지우면 기기의 기록이 지워집니다.

## 가상 마을과 실제 자료 구분

배경과 캐릭터는 학습용 창작 그림이며 실제 대전의 모습을 재현한 지도가 아닙니다. 가상 마을의 ‘과거·현재’와 별도로, 실제 자료마다 지역·연도를 표시합니다. 서로 다른 지역의 농사 자료를 같은 장소의 변화 사진이라고 설명하지 않습니다. 모든 들이 같은 모습으로 바뀌거나 농사가 모두 사라진다고 안내하지 않습니다.

항공사진은 하늘에서 촬영한 실제 사진입니다. 지도 기호 읽기 활동을 함께 할 때는 교과서의 기호 지도와 자료 종류를 구분해 지도하세요. 건물 용도와 인구 증가 등은 사진만으로 확정하지 않습니다.

실제 자료별 원출처·이용 조건·가공 내역은 `SOURCE_NOTES.md`, `PHOTO_CREDITS.md`, `assets/research`의 메타데이터에 있습니다.

## 주요 파일과 검증

- `src/game.js`: 아바타·탐험·주민 대화·조사 의뢰 연결
- `src/research.js`, `research.css`: 실제 자료 조사 화면과 수첩
- `src/research-model.js`: 관찰 기록·좌표 표시·저장 복원·수첩 출력
- `src/research-data.js`: 실제 자료의 질문·연도·지역·출처
- `assets/research`: 항공사진·기록 사진·발췌 영상·출처 메타데이터
- `src/world.js`, `src/state.js`, `src/motion.js`, `src/walker.js`: 길 탐색·진행·보행

`npm test`로 이동·게임 진행·저장 복원·단서 좌표·시기별 표시·수첩의 사용자 입력 이스케이프 검사를 실행합니다. 외부 패키지 설치가 필요하지 않습니다.

개발 검증: Chrome 미리보기에서 항공사진 비교, 사진 위 단서 표시, 관찰·추리 기록 저장과 새로고침 후 복원, 실제 모내기 영상 재생을 확인했습니다. 자동 검사 20개가 통과했습니다. 브라우저 자동화 환경에서는 내려받기 완료 이벤트를 받지 못해 실제 파일 저장 완료는 확인하지 못했으며, 생성된 파일을 다시 받을 수 있는 링크를 유지합니다. Galaxy Tab 실기기 터치와 파일 저장은 추가 확인이 필요합니다.
