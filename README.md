# 들빛마을 시간여행 탐정단 v4.3.1

초등학교 4학년 사회 ‘들이 펼쳐진 지역의 특징과 변화’ 수업용 마을 탐험 게임입니다. 학생 아바타가 주민을 만나 실제 자료를 받고, 과거와 최근의 단서를 따로 모은 뒤 두 자료를 비교합니다.



## 대화 중 아바타 방향 수정 · v4.3.1

주민에게 도착한 마지막 걸음이 위쪽 방향이면 대화 중에도 뒷모습이 유지되던 문제를 수정했습니다. 대화·주민의 실제 자료를 열 때 정면의 멈춘 자세로 바꾸고, 도착한 프레임의 이동 방향이 이를 덮어쓰지 않도록 했습니다. 평소 위로 걸을 때는 뒷모습을 정상적으로 사용하며, 단서·미션·이동 경로는 유지합니다. 자동 검사 45개가 통과했고, 브라우저에서 이동 후 주민 만나기와 부엉 박사 대화 중 정면 자세를 확인했습니다.


## 이동과 주민 간격 개선 · v4.3

- 길 가장자리와 곡선·교차로에서 방향키와 조이스틱이 멈추던 현상을 수정했습니다. 길 앞쪽을 보며 부드럽게 방향을 잡고, 건물·논밭 통과 제한은 유지합니다.
- 낮은 화면 갱신 빈도에서도 경과 시간만큼 움직이되 짧은 단계로 나눠 도로 충돌을 확인합니다. 다른 탭으로 전환하면 걸음을 멈추고 돌아온 시점부터 이어갑니다.
- 조이스틱 중앙의 작은 떨림은 방향 입력으로 처리하지 않으며, 다른 손가락을 떼어도 현재 조작이 취소되지 않게 했습니다.
- 주민은 걷는 길 옆으로 옮겼습니다. 다정 선생님은 주거지 옆 놀이터에서 만납니다. 주민을 누르면 몸과 이름표가 겹치지 않는 도로 위치까지 걸어가 멈추며, 만나러 간 주민이 가장 가까운 이웃이 되도록 위치를 고릅니다.
- 직접 지나갈 때는 발이 겹치지 않도록 확인하고, 가까운 이름표는 잠시 숨깁니다. 긴 탐정 이름은 화면에서 줄여 표시하고 이름 전체는 유지합니다.
- 새 탐험·이어하기에서 겹친 저장 위치를 가까운 안전한 길로 보정합니다. 모은 단서와 비교 기록은 그대로 이어집니다.

검증: 자동 검사 **43개** 통과. 브라우저에서 새 시작·이어하기, 방향키 이동과 반대로 되돌아오기, 조이스틱 끌기, 주민 도착 후 실제 자료 표시와 복귀, 캐릭터·이름표 간격을 확인했습니다. Galaxy Tab 실기기는 별도 확인이 필요합니다.


## 화면 가득 마을 탐험 · v4.2

마을에 도착하면 양옆 빈 여백 없이 화면을 채운 넓은 마을 보기를 먼저 보여 줍니다. 배경 비율을 유지해 확대하며, 화면 밖의 위치는 작은 지도와 목적지 안내로 찾아갈 수 있습니다. 주민 또는 길을 누르면 실제 그림 속 도로·교차로·다리를 따라 경로를 찾고, 화면이 부드럽게 가까워져 탐정의 걸음을 따라갑니다. 건물·논밭·하천을 가로지르는 이동은 제한합니다. 도착할 때는 주민 앞에서 멈춰 대화와 실제 자료를 엽니다.

- **마을 전체**: 화면을 가득 채운 넓은 보기로 마을과 목적지 방향을 살펴봅니다.
- **가까이 걷기**: 걷는 탐정을 따라 주변 풍경을 봅니다. 이동을 시작하면 자동으로 이 보기로 바뀝니다.
- **길 따라 찾아가기**: 현재 의뢰의 주민까지 도로를 따라 걸어갑니다. 경로가 점선으로 표시됩니다.
- **잠깐 멈춤**: 자동 걷기를 중단합니다. 조이스틱이나 방향키로도 걷기를 바꿀 수 있습니다.

주민의 위치도 도로에 맞춰 조정했습니다. 버튼은 도톰한 테두리와 눌림 효과를 적용했습니다. 제목·짧은 버튼은 둥근 주아 서체를, 설명문·대화·자료 설명·학생 입력은 읽기 편한 고딕체를 사용합니다. 본문용 Noto Sans KR과 장식용 주아는 모두 파일에 포함되어 외부 글꼴 연결 없이 표시됩니다. 라이선스는 `assets/fonts`의 OFL 문서와 `FONT_CREDITS.md`를 확인하세요.


## 주민을 만나 이어지는 게임

별도 ‘실제 자료 조사소’와 ‘현장 조사’ 메뉴를 제거했습니다. 주민을 누르면 길을 따라 걸어간 뒤 그 시기의 실제 자료가 바로 열립니다. 옆에서 ‘주민 만나기’를 누르거나 E·스페이스로도 만날 수 있습니다.

1. 부엉 박사의 의뢰를 받고 주민을 찾아갑니다.
2. 과거 또는 현재에 주민을 만나 실제 자료 한 가지를 받습니다.
3. 사진·영상에서 직접 본 모습을 한 줄로 쓰고, 해당 시기의 단서를 수집합니다. 사진에는 위치를 표시할 수도 있습니다.
4. 시간을 바꾸고 같은 주민을 다시 만나 다른 시기의 자료를 받습니다. 자료를 보기 전에 수첩에서 미리 열 수는 없습니다.
5. 두 단서를 모으면 나란히 또는 겹쳐 보며 비교합니다. 달라진 모습과 그 근거를 적고 ‘비교 단서 카드 완성’을 눌러 의뢰를 마칩니다. 비슷하게 남아 있는 모습은 선택 기록입니다.
6. 농사 방법과 땅의 쓰임, 두 비교 카드를 모두 완성하면 부엉 박사에게 최종 보고합니다.

‘목적지 찾기’는 해당 주민에게 걸어가 만나는 동작까지 이어집니다. 주민을 자유롭게 만나 다른 의뢰의 단서를 먼저 모을 수도 있습니다. 자료 조사 중에는 아바타 이동이 멈춥니다.

## 실제 자료

| 주민·의뢰 | 과거 단서 | 최근 단서 |
|---|---|---|
| 들녘 할아버지 · 농사 방법 | 1989년 5월 19일 경기 김포 손모내기 사진 | 2022년 제작 기계 모내기 영상 |
| 다정 선생님 · 땅의 쓰임 | 대전 갑천 주변 1970년 항공사진 | 같은 범위의 2021년 항공사진 |

농사 자료는 서로 다른 지역의 사례이며 같은 장소의 연속 기록은 아닙니다. 대전 항공사진은 동일 범위·방향으로 맞췄습니다. 2021년 자료를 오늘 촬영한 사진으로 표시하지 않습니다. 사진만으로 인구수나 건물의 정확한 용도를 확정하지 않습니다.

초록 이모는 비닐하우스 사진과 온실 영상을 현재 농업의 참고 자료로 보여 줍니다. 두 자료는 같은 장소의 과거·현재 변화 증거로 비교하지 않으며, 보조 메모를 남길 수 있습니다. 만들기 대장·이야기 선생님·길잡이 아저씨도 땅의 쓰임 자료를 건넵니다.

## 단서 수첩

상단 수첩에는 실제로 수집한 시기의 자료만 나타납니다. 아직 수집하지 않은 자료는 잠겨 있습니다. 과거·현재 단서를 모두 모으기 전에는 비교 카드를 완성할 수 없습니다. 수첩을 내려받으면 수집한 사진·위치 표시·관찰 문장·비교 기록·출처가 포함됩니다. 영상은 대표 사진과 원문 링크로 담습니다. 게임에서는 동일한 실제 클립의 WebM·MP4 두 형식으로 재생 호환성을 높였습니다. 내려받기가 바로 시작되지 않으면 화면에 남은 ‘준비된 단서 수첩 받기’를 누를 수 있습니다.

기록은 같은 기기·브라우저에 저장됩니다. 로그인·Firebase·학생 정보 서버 전송은 없습니다. 새 탐험을 시작하면 해당 기기의 진행과 단서를 초기화합니다. 이전 버전의 가상 단서·퀴즈 완료를 새 실제 자료 단서로 간주하지 않습니다. 이전 탐정 이름·아바타·위치는 이어받을 수 있습니다.

## GitHub · Vercel 배포

1. 압축을 풀고 안의 파일과 폴더를 저장소 최상위에 모두 올립니다. 이전 파일을 함께 덮어쓰세요.
2. 실제 실행에는 `index.html`, `app.js`, `style.css`, `assets/`가 필요합니다. `src/`, `scripts/`는 수정·재빌드를 위한 원본입니다.
3. 첫 화면에 **v4.3.1**이 보이는지 확인합니다. HTML과 이전 스크립트를 섞어 올리지 마세요. 이번 버전은 모든 JavaScript를 하나의 `app.js`로 묶어 새 모듈 누락과 파일 혼합을 줄였습니다.
4. Vercel Framework Preset은 **Other**, Build Command는 비움, Output Directory는 **.** 입니다. 포함된 `vercel.json`을 그대로 사용할 수 있습니다.
5. 별도 환경변수·API 키·Firebase 설정이 없습니다. JavaScript 원본을 수정했다면 배포 전에 `npm run build`로 `app.js`를 다시 만듭니다.

`research.css`는 편집용 스타일 원본입니다. 배포 `style.css`에는 해당 스타일이 함께 포함되어 있습니다. 스타일 원본을 수정할 때에는 `style.css`의 `BEGIN RESIDENT EVIDENCE STYLES` 부분을 최신 원본으로 교체하고, 뒤에 있는 `BEGIN COZY GAME UI v4.1` 구역은 유지합니다.

## 검증과 자료 출처

`npm test`로 길·보행·게임 진행, 시기별 실제 단서 수집, 두 시기와 비교문이 필요한 완료 조건, 이전 기록 이관, 미수집 자료 비공개와 내보내기 안전성을 검사합니다. `npm run build`는 외부 패키지 없이 실행됩니다.

자료별 지역·연도·가공 내역·이용 조건은 `SOURCE_NOTES.md`, `PHOTO_CREDITS.md`, `assets/research`의 메타데이터에 있습니다. 게임 배경은 학습용 가상 마을이며 실제 대전 지도와 구분합니다.


브라우저 확인(v4.1): 전체 지도에서 시작하기, 도로·다리를 따라 이동하는 가까이 걷기, 중간 멈춤과 재출발, 이동 중 전체 보기 전환, 보기 버튼의 Space 키 조작, 주민 도착 시 실제 자료 자동 열림과 관찰문 입력·단서 수집을 확인했습니다. 호환 영상의 실제 재생과 관찰문 입력 뒤 단서 수집 버튼 활성화도 확인했습니다. 자동 검사 34개가 통과했습니다. Galaxy Tab 실기기는 별도 확인이 필요합니다.

## 화면·글꼴 조정 · v4.2

전체 보기의 확대 비율을 화면을 채우는 방식으로 바꿔 가로로 긴 화면에서도 양옆 빈 공간을 없앴습니다. 마을 그림과 이동 경로의 비율은 함께 유지합니다. 자세한 설명·자료 출처·관찰 기록과 입력란에는 고딕체를 적용하고, 제목과 버튼의 귀여운 서체는 유지했습니다.

검증(v4.2): 넓은 화면과 태블릿 비율의 여백 없는 배경, 가까이 걷기로 전환할 때의 확대와 화면 경계, 기존 길·단서 수집 조건을 포함한 자동 검사 35개가 통과했습니다.
