# 들빛마을 시간여행 탐정단 v2.1

초등학교 4학년 사회 「다양한 환경과 삶의 모습」 중 ‘들이 펼쳐진 지역의 특징과 변화’ 수업용 탐험 게임입니다.

## 배경 수정: 교과서의 들 지역에 맞춘 시대 설정

과거는 수십 년 전의 비교적 최근 마을입니다. 낮은 주택·학교·가게·도로·작은 작업장이 이미 있는 모습으로 설정했습니다. 현재에는 농업 활동과 함께 아파트·공장·상점·문화 및 체육 시설·기차역 등이 나타나는 모습을 관찰합니다. 특정 연도나 실제 지역을 그대로 재현한 자료는 아닙니다. 기와집·초가집 중심의 전통 마을 배경을 교체했으며, 주민 대사와 수첩의 설명도 바뀐 장면에 맞춰 조정했습니다. 이전 버전의 탐험 진행은 같은 브라우저에서 이어집니다.

## 달라진 게임 방식

- 네 명의 탐정 아바타 중 한 명을 선택합니다.
- 큰 마을을 실제로 걸어 다니며 탐험합니다. 카메라가 탐정을 따라갑니다.
- 부엉 박사에게 첫 의뢰를 받고, 주민과 대화하며 여섯 의뢰를 해결합니다.
- 주민 가까이에서 캐릭터 얼굴과 대사가 있는 화면 아래 대화창이 열립니다.
- 주민에게 이야기를 듣고 반짝이는 현장 단서를 조사합니다.
- 과거·현재를 오가며 같은 장소의 변화 모습을 비교합니다.
- 두 시대의 단서를 모아야 기록 복구 문제에 도전할 수 있습니다.
- 탐정 수첩, 작은 지도, 목적지 안내, 경험치, 완료 인증서 PNG 저장을 지원합니다.

## GitHub · Vercel 배포

1. 압축을 풀고 `index.html`, `style.css`, `src`, `assets`, `package.json`, `vercel.json`, `README.md`를 GitHub 저장소 최상위에 올립니다. `src`와 `assets` 폴더 구조를 유지하세요.
2. 이전 버전의 `index.html`과 `style.css`는 덮어씁니다. 이전 `app.js`는 더 이상 사용하지 않습니다.
3. Vercel에서 해당 GitHub 저장소를 Import합니다. 이미 연결되어 있다면 새 커밋이 배포됩니다.
4. Framework Preset은 **Other**입니다. Build Command는 비워 두고, Output Directory는 **.** 로 설정합니다. 포함된 `vercel.json`도 같은 설정을 선언합니다.
5. 별도 환경변수, Firebase, 사용자 로그인, 유료 API 키는 필요하지 않습니다.

HTML을 파일 앱에서 직접 열기보다 Vercel 주소로 접속하세요. JavaScript 모듈이므로 웹 서버에서 실행해야 합니다.

## 학생 조작

- 바닥 누르기: 길을 따라 해당 위치까지 걷습니다.
- 주민 또는 단서 누르기: 가까이 걸어간 뒤 대화·조사를 시작합니다.
- 조이스틱: 누른 방향으로 이동합니다. 길이 이어진 곳에서 움직입니다.
- 키보드: 방향키 또는 WASD로 이동, E 또는 스페이스로 대화·조사, 스페이스로 대화 넘기기.
- 과거·현재: 부엉 박사의 첫 의뢰를 받은 뒤 시간여행이 열립니다.
- 목적지 찾기: 현재 의뢰의 목적지까지 길을 따라 걷습니다.
- 작은 지도: 노란 점은 목적지, 파란 점은 탐정입니다. 갈 곳을 눌러 이동할 수도 있습니다.
- 수첩: 조사 기록을 확인합니다. 여섯 의뢰와 마지막 보고를 마친 뒤 인증서를 저장할 수 있습니다.
- 설정: 조작 안내와 효과음 설정을 확인합니다.

## 여섯 의뢰

1. 논과 물길: 하천·저수지와 벼농사의 관계
2. 밭과 비닐하우스: 여러 작물과 재배 환경
3. 주거지: 집·아파트 등 주거 시설의 변화
4. 일터: 농업과 회사·공장 등 다양한 일하는 모습
5. 장보기와 문화생활: 장터·상점·문화 시설
6. 교통: 길과 교통 시설, 지역 간 이동

## 자료와 저장

첨부 교과서의 범위를 참고하여 새로 구성한 학습용 가상 마을입니다. 실제 지역이나 특정 연도의 변화를 재현한 자료가 아닙니다. 같은 마을의 과거·현재 배경과 캐릭터는 AI로 제작했습니다. 교과서 그림을 복제하지 않고, 논·밭·비닐하우스와 주거·산업·문화·교통 시설이라는 핵심 내용을 참고하여 새로 그렸습니다. 지역마다 변화 모습이 다를 수 있으며, 모든 들 지역이 똑같이 변화하거나 농업이 모두 사라진다고 설명하지 않습니다.

학생 이름·아바타·위치·진행 상황은 같은 기기와 브라우저의 localStorage에 저장됩니다. 서버나 교사에게 전송하지 않습니다. 로그인, 온라인 공동 플레이, 교사 수집 기능은 없습니다. ‘새로운 탐험 시작’ 후 출발하면 이전 진행을 대체합니다.

## 파일과 검증

- `src/data.js`: 주민, 의뢰, 학습 대사
- `src/world.js`: 길과 이동 경로 탐색
- `src/state.js`: 진행·저장 데이터 처리
- `src/game.js`: 화면, 이동, 대화, 시간여행, 수첩, 인증서
- `tests/game.test.js`: 길 연결, 이동, 의뢰 완료 조건, 저장 복원 검사

`npm test`로 검사를 실행할 수 있습니다. 외부 패키지 설치는 필요하지 않습니다. 개발 중 브라우저 보안 정책이 미리보기 접근을 차단하여 실제 화면·기기별 조작·이미지 다운로드의 브라우저 검증은 완료하지 못했습니다.
